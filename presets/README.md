Site presets: coordinates, timezone, language, and the city's open-data portal, for the four Fab City Index pilots.

    ./install.sh --preset barcelona --name lab-roof --airgradient ag1.local

Everything a preset sets can be overridden by a flag or edited in `.env` afterwards. Nowhere on this list?
Run without a preset and pass `--lat --lon`; a node bootstraps from global sources at any coordinates on earth.
Adding your city is a pull request with one file.
