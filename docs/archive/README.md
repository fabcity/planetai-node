# docs/archive

What was true when it was written, kept because later documents and code comments cite it. Nothing here
describes the node as it is today: read `docs/`, `docs/site/` and the code for that, and never follow an
instruction in this folder without checking it against `main`.

- `handoffs/` — one session's notes to the next, mostly September 2026, each about one release or feature.
- `reviews/` — the September 2026 code, beta-readiness and agent-readiness reviews, and their reconciliation.
- `plans/` — implementation plans and prompts that have since been built, superseded or dropped.

The two handoffs that were still runbooks moved up instead: `docs/SIGNING.md` (the release key) and
`docs/ARM64.md` (the arm64 test plan).
