# The licence, decided

**Decided 25 September 2026 by Tomas: the code is AGPL-3.0-or-later.** He stated it in the build session on
26 September, and it is recorded here that day. This closes [2026-09-18-licence.md](2026-09-18-licence.md), which
set out three options and recommended this one, row (B) of its §6.

The programme site (fabcity/planetai, `web/src/data.js` `LICENCE`) has cited this file since 25 September. Until
now the file did not exist.

## What is decided

- **Code: AGPL-3.0-or-later**, for the node.

## What stays as it is

- **Documentation and pack data: CC-BY 4.0**, as `CONTRIBUTING.md` already says.
- **`NOTICE`**: "Fab City Foundation and contributors".
- **Hardware and the trademark policy** are not decided by this record. The 18 September record's §6 recommends
  CERN-OHL-S and the trademark policy from row (A), and those remain its recommendations.

## When it takes effect

A licence change needs every contributor's consent (the 18 September record, §5). So `LICENSE` stays Apache-2.0
until every contributor has consented, and the change lands at the first tag after that. Every release before
that tag stays Apache-2.0 for anyone who has it: at the time of writing, every release to v0.75.2.

Say it the same way everywhere: **Apache-2.0 today; AGPL-3.0-or-later once every contributor has consented.** A
sentence that names a release ("from the next release") goes wrong the next time a release ships first.

## What this record does not do

It does not edit `LICENSE`, `NOTICE` or `CONTRIBUTING.md`, and it adds no `licence:` key to a pack. The relicence
PR does those things, once the consents are in.
